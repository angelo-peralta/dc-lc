# 07. Payment Workflow

## Office
**Business Affairs Office (BAO)**

## Fee
- Data Consultation: PHP 1,650
- Language Editing: PHP 1,650

Admin must be able to change fees for future effective dates.

## Workflow
Requirements Complete → Student pays at BAO → Student uploads official receipt → Service Coordinator verifies receipt → Assignment becomes available.

## Receipt Fields
- Official Receipt Number
- Payment Date
- Amount Paid
- Receipt File
- Optional Remarks

## Verification Fields
- Status
- Verified By
- Verified At
- Verification Remarks

## Important Rule
CPRINT does not receive or process the money.
