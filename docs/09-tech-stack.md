# 09. Technology Stack

- Laravel
- React + TypeScript
- Inertia.js
- Tailwind CSS
- shadcn/ui
- MySQL
- Eloquent ORM + Query Builder
- Laravel Session Authentication
- Private local/server storage
- Laravel Mail / Notifications
- Laravel Queue
- Ubuntu + Nginx + PHP-FPM

No Prisma, PostgreSQL, Supabase, S3, Microsoft Entra ID, or JWT for normal staff login.
