# 05. Language Editing Module

## Applicant
Undergraduate student / project leader only.

## Required Applicant Information
- Student Number
- First Name
- Middle Name
- Last Name
- School / College
- Program
- Year Level
- Institutional Email
- Contact Number
- Faculty Adviser
- Research Title

## Required Documents
- Thesis / Dissertation Manuscript
- Other Supporting Document

Admin may add future requirements.

## Payment
After requirements are complete, student pays PHP 1,650 at BAO, uploads official receipt, and LE Coordinator verifies it.

## Assignment
LE Coordinator assigns Language Editor only after verified payment proof.

Editor must Accept or Decline with reason.

## Editing
Support multiple edited-manuscript versions.

## Final Review
CPRINT Director performs final review and may return the work for revision.

## Evaluation
Mandatory before final output download.
