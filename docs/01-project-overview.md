# 01. Project Overview

## System Name
**CPRINT Data Consultation and Language Editing System**

## Scope
The system manages two independent CPRINT services:
- Data Consultation
- Language Editing

Both use one platform but remain separate operational modules.

## Main Objectives
- digitize public service requests;
- remove the need for student accounts;
- provide tracking through a tracking number;
- centralize requirement checking;
- record BAO payment proof;
- route cases to the correct specialist;
- provide controlled document access;
- support file versions;
- provide director-level final approval;
- require service evaluation before final release;
- maintain an audit trail;
- support archival export;
- manage 3-year document retention after export;
- generate operational and management reports.

## Main Principle
The system manages a complete case lifecycle, not merely an online form.
