# 21. Deployment

## Suggested Server
Ubuntu Server

## Services
- Nginx
- PHP-FPM
- Laravel
- MySQL
- Queue Worker
- Cron / Scheduler
- Private Storage
- Mail
- TLS

## Backups
Back up:
- MySQL
- private documents
- archive metadata
- secure configuration

Database and files must be backed up together logically.

## Environments
- Local
- Testing
- Staging
- Production
