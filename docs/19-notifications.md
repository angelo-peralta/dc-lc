# 19. Notifications

## Student
- submission received
- requirements incomplete
- requirements complete / pay at BAO
- payment proof rejected
- payment proof verified
- assigned consultant/editor
- output under final review
- evaluation required
- final output available

## Staff
- new submission
- correction uploaded
- receipt uploaded
- assignment declined
- output uploaded
- director revision
- retention nearing expiry

Email is useful but should not block the core workflow.

Built-in messaging is future priority.
