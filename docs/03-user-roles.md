# 03. User Roles

## Public Undergraduate Student / Client
No account.

Can:
- submit request;
- track case;
- edit permitted information;
- upload corrections;
- upload payment proof;
- download own submitted files;
- see assigned consultant/editor;
- complete evaluation;
- download final output after evaluation;
- withdraw before payment.

## Data Consultation Coordinator
- reviews DC requirements;
- returns deficiencies;
- marks requirements complete;
- verifies/rejects receipt;
- assigns/reassigns Data Consultant;
- monitors DC cases;
- archives/exports completed DC cases.

## Language Editing Coordinator
- reviews LE requirements;
- returns deficiencies;
- marks requirements complete;
- verifies/rejects receipt;
- assigns/reassigns Language Editor;
- monitors LE cases;
- archives/exports completed LE cases.

## Data Consultant
- views assigned DC cases;
- accepts/declines assignment;
- accesses authorized files;
- uploads outputs and revisions.

## Language Editor
- views assigned LE cases;
- accepts/declines assignment;
- accesses authorized manuscripts;
- uploads edited manuscript versions.

## CPRINT Director
- reviews outputs;
- returns work for revision;
- approves final release.

## Admin
- manages staff;
- roles;
- fees;
- requirements;
- file types/limits;
- schools/programs;
- system settings;
- reference data.
